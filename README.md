# Sistema de Gerenciamento de Processos Internos

## 1. Sobre o projeto

Este projeto tem como objetivo desenvolver um sistema para gerenciamento de processos internos de uma organização, facilitando a documentação, a análise e a melhoria dos processos organizacionais.

A proposta é permitir que os processos sejam documentados de forma estruturada, identificando suas etapas, os responsáveis envolvidos, as entradas necessárias e as saídas geradas.

O sistema também considera a documentação do processo atual (*AS-IS*) e do processo futuro (*TO-BE*), permitindo representar como um processo funciona atualmente e como poderá funcionar após as melhorias propostas.

## 2. Objetivo

Facilitar o gerenciamento e a documentação dos processos internos de uma organização, contribuindo para a identificação de oportunidades de melhoria e para a organização das informações relacionadas a cada processo.

## 3. Funcionalidades propostas

A partir do prompt utilizado para gerar os requisitos, foram definidas as seguintes funcionalidades esperadas:

- Cadastro de processos internos.
- Descrição das etapas de cada processo.
- Identificação dos responsáveis pelas etapas.
- Registro das entradas e saídas dos processos.
- Documentação do processo atual (*AS-IS*).
- Documentação do processo futuro (*TO-BE*).
- Organização das informações para apoiar a análise e a melhoria dos processos.

## 4. Prompt utilizado no Kiro

O Kiro foi utilizado como ferramenta de apoio à geração dos requisitos do sistema, a partir do seguinte prompt:

> Quero criar um sistema para gerenciamento de processos internos de uma organização.  
> O sistema deve permitir cadastrar processos, descrever suas etapas, identificar responsáveis, registrar entradas e saídas e documentar o processo atual (AS-IS) e o processo futuro (TO-BE).  
> O objetivo é facilitar a documentação, análise e melhoria dos processos.

## 5. Contexto de desenvolvimento

O projeto foi iniciado a partir de uma descrição textual do problema e das necessidades do sistema. O prompt fornecido ao Kiro apresenta o objetivo geral da solução e suas principais funcionalidades esperadas.

A partir dessa descrição, a ferramenta foi utilizada para apoiar a elaboração dos requisitos e a organização das informações necessárias ao desenvolvimento do sistema.

## 6. Conceitos utilizados

- **Gerenciamento de processos:** organização e documentação das atividades realizadas por uma organização.
- **AS-IS:** representação de como um processo funciona atualmente.
- **TO-BE:** representação de como se espera que o processo funcione após as melhorias.
- **Requisitos de software:** descrição das funcionalidades e necessidades que o sistema deve atender.

## 7. Finalidade do projeto

O projeto permite explorar o uso de ferramentas de inteligência artificial no apoio à especificação de requisitos de software, utilizando como exemplo um sistema de gerenciamento de processos internos.
